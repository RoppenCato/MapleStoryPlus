# Research: what other servers changed about classes

Looked up on 2026-10-10 as input for the class work in [Class-Changes.md](Class-Changes.md). These are other servers' choices, not our decisions.

## Which servers

| Server | Version | What it is | How much was readable |
|--------|---------|------------|-----------------------|
| MapleRoyals | v62-based | Large long-running classic server. Publishes detailed skill changes with reasons. | Good: one full update post and a long change list |
| MapleStory Classic World | Official, by Nexon | Nexon's own classic server, launched 2026-10-06. Changes read from a fan site's notes. | Good for 1st and 2nd job |
| MapleLegends | v62-based | Large classic server. | Nothing found on skill changes |
| ClassicStory+ | v83 | Smaller server with custom class balance, including a new archer mobility passive. | Page could not be opened |
| Dream MS, Kaizen | v92 | Custom-content servers. | Nothing found on skill changes |

Player numbers for 2026 could not be verified for any of them.

## Patterns worth copying

1. **Fix the reason nobody uses a skill, not just its damage.** Royals' notes almost always name the cause: a buff that overwrote potions so nobody put points in it, a cooldown that discouraged use, a range that made the skill no better than the one before it.
2. **Make each job's main attack a real upgrade over the last one.** Royals widened Charged Blow because it was not better than Slash Blast for groups. This is the same problem as Savage Blow against Double Stab.
3. **Raise target counts on area attacks.** Classic World took Slash Blast, Rush, Arrow Bomb, Iron Arrow and Poison Breath from 4 targets to 6.
4. **Late scaling instead of a flat buff.** Royals raised Avenger only from level 21 up (180% to 200% at max), so the last ten points are worth spending.
5. **Rework passives nobody feels.** Classic World swapped dull defensive bonuses for offensive ones: Sword Mastery gives accuracy instead of weapon defence, Bow Mastery gives critical rate and speed instead of evasion.
6. **Class buffs that stack with potions.** Royals made Rage, Dragon Blood and Meditation stack with attack potions, so the buff is always worth casting.
7. **Quality of life on core skills.** Dark Sight became a toggle and any attack leaves it. Recoil Shot's cooldown was halved.
8. **Give the weak-mobility classes something.** ClassicStory+ added a passive for archers that raises movement and jump. Players on Royals ask for Assaulter to be faster so it feels like movement.

## Changes by class

### Thieves

| Server | Skill | Change |
|--------|-------|--------|
| Royals | Dark Sight | Pressing it again cancels it; any attack leaves it; Hero's Will usable inside it |
| Royals | Haste | Larger party range |
| Royals | Assaulter | Stuns monsters |
| Royals | Meso Guard | Lasts 180 seconds at max |
| Royals | Boomerang Step | Usable at ledges and on slopes; shorter delay between hits; damage raised to 600% |
| Royals | Assassinate | Raised to 950%; no Dark Sight charge needed for full damage; slightly longer reach |
| Royals | Smokescreen | 90 seconds at max, but only one per map per 150 seconds |
| Royals | Taunt | Bonus exp and drops also apply when Taunt lands the kill |
| Royals | Avenger | 200% at max instead of 180%, scaling from level 21 |
| Royals | Shadow Shifter | Lowered to 30% for Shadowers and 20% for Night Lords |
| Royals | Alchemist | Lowered from 150% to 125% |
| Classic World | Steal | Attack buff after a successful steal lasts 60 seconds instead of 30 |
| Royals (player ideas) | Assaulter | Half the animation time and longer travel, so it works as movement |
| Royals (player ideas) | Savage Blow | Keep it useful in 4th job instead of abandoning it |
