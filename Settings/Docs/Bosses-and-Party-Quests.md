# Bosses and party quests

Everything the server has, read from its data and scripts. **Built automatically** by `Settings/Reference/Build-Reference.py`; do not edit by hand. Nothing here is tested in the game, so "available" means the server has it, not that it works.

The same content as sortable lists: [Bosses.tsv](../Reference/Bosses.tsv) and [PartyQuests.tsv](../Reference/PartyQuests.tsv).

Player counts are the original requirements. The setting `USE_ENABLE_SOLO_EXPEDITIONS` (off) lowers the expedition bosses to 1 player. Party quests have no such setting.

## Not in these lists

- **Mu Lung Dojo** and **Monster Carnival** are built into the server code, not event scripts. Monster Carnival is switched on (`USE_CPQ`).
- **Ariant Coliseum** is an expedition type in the server code (2 to 7 players, level 20 to 30).
- Event and party quest copies of bosses are left out (monster IDs from 9000000 up, except the world tour, New Leaf City and Crimsonwood range 9400000 to 9499999).
- The time limit is the script's main timer. For a few (Crimsonwood Keep PQ, Pirate PQ) that is only the first stage.
